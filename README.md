# Python Learning

A structured repository containing Python concepts, hands-on notebooks, practice scripts, and foundational projects.

## Structure & Topics

- **Data Structures (`DS/`)**:
  - Lists (`List.ipynb`)
  - Dictionaries (`dictionary.ipynb`)
  - Tuples (`tuples.ipynb`)
  - Sets (`set.ipynb`)

- **Functions (`Functions/`)**:
  - Function basics and arguments (`function.ipynb`)
  - Lambda functions (`lamba_functions.ipynb`)
  - Higher-order functions (`map_function.ipynb`)

- **Object-Oriented Programming (`OOPS/`)**:
  - Classes, Objects, and Methods (`oops.py`, `a.py`)

- **Error & File Handling (`Errorhandling/`)**:
  - Exception handling (`error_handling.ipynb`, `main.py`)
  - File reading and writing operations (`file_handling.ipynb`)

- **Mini Projects**:
  - Student Management System (`studentManagement/main.py`)
